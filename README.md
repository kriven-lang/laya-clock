# Laya Clock

An interactive Carnatic tala and nadai practice clock.

## Production

The production app is `index.html`, based on **V4 · Full-cycle subdivision geometry**. Experimental V5 and V6 remain archived under `history/` and are not used for production.

## History

The `history/` directory preserves seven distinct HTML versions plus the second original file (`laya-clock(1).html`), which is byte-identical to `laya-clock.html`.

## Run locally

Open `index.html` in a modern browser. Press Play to enable audio. Keep the tab active for best timing.

## Deployment

GitHub Pages serves the repository root from the `main` branch.
